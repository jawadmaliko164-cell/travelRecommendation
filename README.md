# WanderWise Travel Recommendation

Course final project implementation for the Travel Recommendation Web Application.

## Files
- `travel_recommendation.html` — main webpage
- `travel_recommendation.css` — styling
- `travel_recommendation.js` — Fetch API, search, DOM manipulation and events
- `travel_recommendation_api.json` — recommendation data

## Run
Open `travel_recommendation.html` with VS Code Live Server. This is important because the browser Fetch API may block local `file://` JSON access.

## Required searches
- beach / beaches / BEACH
- temple / temples / TEMPLE
- country / countries / COUNTRY
